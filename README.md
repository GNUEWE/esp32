# ESP32 Projects

A collection of ESP32 projects and examples.

## Projects

### ESP32-CAM Captive Portal
A minimal ESP32-CAM AI-Thinker project that creates an offline captive portal with live camera feed.

**Features:**
- Open WiFi Access Point (no password)
- Automatic captive portal redirection
- Live camera snapshot with auto-refresh
- Fully offline operation
- Beautiful, responsive UI
